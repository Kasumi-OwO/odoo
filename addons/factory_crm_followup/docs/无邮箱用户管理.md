# 无邮箱用户管理

本模式适合暂时不配置 SMTP、用户数量较少且由管理员统一开户的内部 CRM。

## 已禁用的功能

- 公开自由注册；
- 登录页“忘记密码”邮件重置；
- 新建用户时自动发送邀请邮件；
- 用户页面的“发送邀请”和“发送密码重置”按钮；
- 新内部用户的邮件通知，通知默认只显示在 Odoo 收件箱中。

客户、商机、活动、跟进和 Odoo 站内通知不受影响。

## 创建业务员账号

1. 管理员进入 **设置 → 用户与公司 → 用户**；
2. 点击“新建”，填写姓名和唯一的登录邮箱；
3. 用户类型选择“内部用户”；
4. 销售权限选择“用户：仅自己的文档”；
5. 选择公司、销售团队、简体中文和时区；
6. 保存。保存过程不会发送邮件；
7. 打开该用户的 **安全** 页签；
8. 点击 **修改密码**，在弹出的列表中输入初始密码并确认；
9. 通过安全方式单独把登录名和初始密码交给业务员。

电话和地址均不是必填项。

## 用户首次登录

业务员使用管理员提供的登录名和初始密码登录。登录后进入个人偏好或安全设置，立即修改自己的密码。

不要在客户备注、商机跟进、群聊或公开文档中传递密码。

## 忘记密码

1. 用户联系管理员；
2. 管理员打开该用户；
3. 进入 **安全 → 修改密码**；
4. 设置新的临时密码；
5. 用户登录后再次修改。

无邮箱模式下，登录页面不能自行找回密码，这是刻意的安全限制。

## 将来启用邮箱

准备好企业 SMTP、SPF、DKIM 和 DMARC 后，应先在测试环境恢复邮件邀请和密码重置，再切换生产配置。不要只添加 SMTP 就立即开放公众注册。
